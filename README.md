# BlogPoint

**BlogPoint** is a modern blogging platform that allows users to create, read, update, and delete (CRUD) blog posts. It offers a seamless user experience, with an intuitive UI built using **React** and **Tailwind CSS**, and robust backend functionalities powered by **Appwrite**.

## Features

- User Authentication and Authorization
- Create, Read, Update, and Delete blog posts
- Responsive and clean UI with Tailwind CSS
- Real-time data synchronization
- Secure and scalable backend with Appwrite

## Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Appwrite
- **Database**: Appwrite's built-in Database
